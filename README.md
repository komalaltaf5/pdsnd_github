### Project Title
BikeShare Data Analysis

### Description
This project analyzes US bikeshare data from three major cities: Chicago, New York City, and Washington. 
Using a Python script, the program allows users to filter the data by month and day of the week, 
and it computes various descriptive statistics such as popular travel times, stations, trip durations, 
and user demographics.

- chicago.csv
- new_york_city.csv
